# 需求：库存预警报告

## 背景

仓库管理员每天需要知道哪些商品需要补货。当前只能调用 `needs_reorder()` 得到“低于或等于补货线”的条目，但无法按自定义阈值筛选，也无法直接看到缺口数量。

## 目标

为 `Inventory` 增加一个公开方法：

```python
def low_stock_report(self, threshold: int = 0) -> List[dict]:
    ...
```

返回一个按 SKU 升序排列的列表，每项包含：

- `sku`
- `name`
- `quantity`
- `reorder_level`
- `deficit`：`max(reorder_level, threshold) - quantity`，且不小于 0

## 筛选规则

- `threshold` 必须是大于或等于 0 的整数；否则抛出 `ValueError`。
- 当 `threshold` 为 0 时，只报告 `quantity <= reorder_level` 的条目。
- 当 `threshold` 大于 0 时，报告 `quantity <= max(reorder_level, threshold)` 的条目。
- `deficit` 用 `max(reorder_level, threshold) - quantity` 计算。
- 返回的是普通 `dict`，不是 `Item`，避免调用方修改内部对象。

## 约束

- 不引入第三方依赖。
- 不改变 `needs_reorder()` 的现有行为。
- 保持 Python 3.10+ 类型标注。
- 新增测试，覆盖：
  1. 默认阈值；
  2. 自定义阈值；
  3. 负数阈值被拒绝；
  4. 返回结果按 SKU 排序；
  5. `deficit` 计算正确。
